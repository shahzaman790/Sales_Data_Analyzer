# 📊 Sales Data Analyzer

## 📌 Project Overview
This project analyzes sales data using Python and Pandas.

## ✨ Features
- Read sales data from CSV
- Calculate total sales
- Calculate average sales
- Find the best-selling product
- Display a sales bar chart using Matplotlib

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
